Grok Reels Library

Pure browser tool for browsing and downloading your vertical (9:16) Grok generations. No extension required.

Install the bookmarklet

Drag the button below to your bookmarks bar.

⭐ Reels Library
Safari: View → Show Bookmarks Bar (or ⌘⇧B) if the bar is hidden.
After dragging, the bookmark is ready to use.

How to use

  1. Log in to Grok and open https://grok.com/library or https://grok.com/imagine.
  2. Click the Reels Library bookmark.
  3. A floating 9:16 grid appears.
    • Click an item to select / deselect it (green outline).
    • Double-click an item to open the full media.
    • Use the search box and Image/Video filter.
    • Click Download selected (N) to save the chosen files directly in the browser.

Downloads use your existing login session. Files are saved with their original names when possible.
