Grok Reels Library v3

Full-screen 9:16 scan of your Imagine images and videos. Runs in Safari on grok.com. No extension.

Replace the old bookmark. The one already on your bar is a frozen copy of the broken script (the header does not say v3, and the search box says “Search prompts…”). Dragging is required once. After that, this page always builds the button from the latest script.

1. Drag this to the bookmarks bar

Reels Library v3
Safari: View → Show Bookmarks Bar (⌘⇧B).
If a bookmark named “Reels Library” is already there, delete it, then drag Reels Library v3.

2. Open your library and click the new bookmark

  1. Log in and open https://grok.com/library.
  2. Click Reels Library v3.
  3. The header must say Reels Library v3 in green. If it does not, you clicked the old bookmark.
  4. Images and videos fill the screen as pages load. You do not open each item to see it. Videos play while you scroll.
  5. A row labeled “in this cycle” is one image plus the videos made from it, side by side. Everything else sits in the 9:16 grid under that.
  6. Click to select. Double-click to open the file. Download selected saves the files in the browser.

If Safari only saves the first download, allow multiple downloads for grok.com: Safari → Settings → Websites → Downloads.
