  1. Log in and open https://grok.com/library.
  2. Click Reels Library v5.
  3. The header must say Reels Library v5 in green. If it still says v4, you clicked the old bookmark.
  4. Search matches the generation prompt. The first search can take a moment while those prompts load. The status line shows the progress.
  5. Video tiles use a still image. Hover one to play it.
  6. A row labeled “in this cycle” is one image plus the videos made from it, side by side. Everything else sits in the 9:16 grid under that.
  7. Click to select. Double-click to open the file. Download selected saves the files in the browser.

If Safari only saves the first download, allow multiple downloads for grok.com: Safari → Settings → Websites → Downloads.
